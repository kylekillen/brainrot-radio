# Build-Pitch of the Day — 2026-11-08

## Pitch 1 (primary): Adopt the advisor pattern — Fable plans, Sonnet executes — instead of hand-rolling an orchestrator loop

**Technique.** Anthropic shipped the advisor tool (`advisor_20260301`, server-side API beta) and an `/advisor` command in Claude Code. A cheaper executor model (Sonnet) calls the advisor mid-task as a normal tool; the server passes the full conversation to the advisor, which returns ~400–700 tokens of guidance with reasoning stripped — in a single request. Anthropic's SWE-bench Pro benchmark (482 curated tasks): Sonnet 5 + Fable 5 advisor ≈ 84% pass rate vs Sonnet 5 alone ≈ 75.5%; the advisor pair captured ≈92% of Fable 5's solo score (91.5%) at ≈63% of the cost (~$1.40/task vs ≈$2.25/task solo Fable). Anthropic frames Fable as the planner that delegates execution to smaller models; advisor use is recommended for long-horizon agentic coding work, with suggested system-prompt language to encourage mid-task and pre-completion consultations (executors under-call advisors by default).

**Who's doing it.** Anthropic — advisor tool + `/advisor` + SWE-bench Pro write-up (primary sources: Anthropic platform docs / claude.com). No YouTube claude_lab creator cleared the bar today: full-transcript pulls for this week's candidates (Cole Medin's software-factory and open-models videos, IndyDevDan's tiny-factories) all failed (yt-dlp HTTP 429; yt-search "No transcript available"), so nothing is sourced from a practitioner video today.

**Evidence it's real.** Primary-source benchmark + server-side beta tool + shipping command, corroborated by our own fleet design independently converging on the same shape — Phase 6 (approved 2026-07-11), "Build execution = Fable orchestrator handing jobs to cheaper subagents (M1 being built by a sonnet worker under FO direction)" — with the design doc parking the advisor as "not building on the advisor tool now; it's API-billed and credits are off." The pattern is therefore no longer only a fleet-internal hypothesis; it is Anthropic's productized mechanism with published quality/cost evidence behind it.

**Need it serves.** Priority 2 (income — AI businesses): the multi-agent collaboration that carries work forward without Kyle's constant attention, now real at planner/executor scale rather than hand-rolled dispatch. Adjacent to priority 1 (screenwriting attention) via cheaper agent loops, and to priority 3 (trading-bot resilience) if advisor wiring ever lands in the responder lane.

**Delta vs Kyle's current setup.** The fleet is mid-build of exactly this orchestrator (Phase 6 M1, sonnet worker). The delta is adopt-vs-build: use Anthropic's advisor mechanism (and the `/advisor` command) as the orchestrator→executor handoff instead of hand-rolling it. **Whole-fleet leverage.** One adopt per agent loop: Fable plans, Sonnet executes with advisor consultation; bounded advisor output (~400–700 tokens) keeps orchestrator context lean — a fleet-wide context/state optimization.
