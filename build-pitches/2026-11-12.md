# Build-Pitch of the Day — 2026-11-12

## Pitch 1 (primary): Adopt Claude Code scheduled tasks (formerly "Routines") as the fleet's proactive-agent mechanism — retire hand-rolled launchd + cron + `claude -p` dispatch.

**Technique.** Claude Code's shipped scheduled tasks (cloud; formerly "Routines") package a prompt + one or more repos + connectors into one saved config and run it autonomously on a schedule, an API trigger, or a GitHub event, on Anthropic-managed cloud infrastructure; sessions are steerable mid-run, and triggers can be combined.

**Who's doing it.** Anthropic — "Day 1 of Code with Claude" workshop (Maya, Applied AI): "coding agents shouldn't wait for you to press enter to get started… we created this feature called routines to take Claude Code from a tool today into the teammate of tomorrow"; shipped surface at `code.claude.com/docs/en/routines.md` + CLI `/schedule` + `/loop`; changelog entries for `/schedule`, cloud scheduled tasks, GitHub triggers. Practitioner corroboration: IndyDevDan, "ZERO to RUNNING Software Factory In 16 Minutes (LIQUID Software)" and "Tiny Software Factories: Agentic Engineering DONE WRONG" — the in→near→out-of-the-loop progression.

**Evidence it's real.** Primary sources converge (docs + workshop + changelog). Workshop: proactive agents beat reactive agents; Anthropic internally saw weekly Claude Code PRs up ~200% since the start of the year, driven by routines. Practitioner: LIQUID software factory — proactive agents work around the clock and only stop at decisions that need the human; "you are the bottleneck" when stuck in the loop.

**Need it serves.** Fleet pain: autonomous loops (podcast generator, beat reporters, QC, build-pitch reporter, sentinel triage) are reactive, dispatched out of hand-rolled launchd + cron + `claude -p`. Goal-bound execution was adopted 2026-11-11 (delegate an outcome, not a turn) — the next gap in that arc is proactivity: agents that don't wait on a human/loop to start. Serves priority 2 (AI businesses: multi-agent collaboration that carries work forward without Kyle's constant attention) primarily; priority 1 (screenwriting attention / friction) secondarily; priority 3 (trading resilience) via deploy-verifier and alert-triage routines.

**Delta vs Kyle's current setup.** He hand-rolls launchd plists + cron + `claude -p` and dispatches via goal-bound workers (2026-11-11). The shipped scheduled task replaces that glue with managed hosting, triggers, connectors, steerability, and run history — and adds event triggers (GitHub PR merged → doc sync; deploy → verify/rollback; issue → triage) that polling/cron can't do.

**Whole-fleet leverage.** One adoption per agent loop: podcast generator, beat reporters, QC, build-pitch reporter, deploy verifier, on-call triage become managed scheduled tasks instead of hand-rolled cron + `claude -p`.
