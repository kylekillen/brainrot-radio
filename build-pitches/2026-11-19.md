# Build-Pitch of the Day — 2026-11-19

## Pitch 1 (primary): Adopt Claude Code v2.1.328 — headless subagents wait for their own subagents.

**Technique.** Ship Claude Code v2.1.328 (released 2026-11-19) so that subagents in headless runs (`claude -p`, Agent SDK, desktop, VS Code) wait for their own subagents by default when `CLAUDE_CODE_FORK_SUBAGENT=0` is set; a background subagent plus the subagents it waits for now count against one 10-minute wait, with the ceiling raiseable via `CLAUDE_CODE_PRINT_BG_WAIT_CEILING_MS` for longer chains.

**Who's doing it.** Anthropic — GitHub release `anthropics/claude-code` **v2.1.328** (published 2026-11-19T01:14:04Z), changelog (code.claude.com/docs/en/changelog), Agent SDK TypeScript **v0.3.328** parity notes, sub-agents docs (code.claude.com/docs/en/sub-agents). Corroborated by changelog-coverage roundups.

**Evidence it's real.** Verified against the official GitHub release + changelog + sub-agents documentation + Agent SDK parity notes, which converge on the same v2.1.328 entry. Related fixes shipped in the same release: background agents no longer report "still running" after an SDK interrupt stopped them; background-agent permission-prompt reporting fixed; auto-mode reply-drop issues fixed.

**Need it serves.** Fleet pain: autonomous loops — dispatched task workers, the PR-reviewer loop, the podcast beat reporters + multi-pass writer, the build-pitch reporter, QC, sentinel triage — run multi-agent orchestration headless through `claude -p` (one fresh instance per worker via `/delegate`, in-task subagents proven live in fleet use). The orchestrator-waits guarantee those designs lean on is now shipped and default-able for headless. Serves priority 2 (AI businesses: multi-agent collaboration carrying work forward without Kyle's constant attention) primarily; priority 1 (screenwriting) via a less-fragile content pipeline; priority 3 (trading resilience) via convergent, verifiable agent work.

**Delta vs Kyle's current setup.** Kyle has the delegation setup, `/goal` conventions, Code Mode (v2.1.323), staged-ship and the Independent Outcome Grader — but not the headless subagent-wait behavior, which needed this release plus the explicit `CLAUDE_CODE_FORK_SUBAGENT=0` setting. Delta: upgrade the fleet CLI to ≥v2.1.328 and set the env var on headless invocations; raise the background-wait ceiling for long chains.

**Whole-fleet leverage.** One adoption per autonomous loop: dispatched workers, PR-reviewer loop, beat reporters/write/QC/build-pitch reporter, sentinel triage all inherit deterministic nested-subagent waits in headless runs.

**Build sketch.**
1. Upgrade the fleet Claude Code CLI to ≥v2.1.328 on the Mac mini (and any other fleet hosts).
2. Set `CLAUDE_CODE_FORK_SUBAGENT=0` on headless invocations (`claude -p` worker spawns / `/delegate` workers).
3. Set/confirm `CLAUDE_CODE_PRINT_BG_WAIT_CEILING_MS` for longer agent chains.
4. Verify with a known nested-subagent loop (in-task subagent test / build-pitch reporter chain).
5. Rollback: unset env var / pin CLI version.
