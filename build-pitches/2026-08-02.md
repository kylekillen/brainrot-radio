## Pitch 1 — Anthropic's own "new rules of context engineering" (80% system-prompt cut, `claude doctor` right-sizing) haven't been run against any of the fleet's own CLAUDE.md files

**Technique.** Anthropic's Claude Code team published "The new rules of context engineering for Claude 5 generation models" and, in the same window, cut Claude Code's own system prompt by over 80% for Opus 5/Fable 5-class models with no measurable loss on coding evaluations. The article names six concrete shifts: (1) rules become judgment — stop writing prescriptive worst-case rules ("default to writing no comments") and trust the model's judgment on context-dependent calls; (2) examples become interface design — better-designed tool parameters beat usage examples; (3) upfront context becomes progressive disclosure — move detailed guidance out of the system prompt/CLAUDE.md into skills the model loads only when needed ("lazy loading"); (4) CLAUDE.md should be brief and repo-specific-gotchas-only, not a place to cram everything; (5) `claude doctor` (the `/doctor` command, already shipped in the installed binary) does an automated, read-only-first audit — install health, dead/unused skills and MCP servers, CLAUDE.md redundancy, and where always-loaded guidance should be a skill/subdirectory instead — before asking permission to fix anything it finds.

**Who's doing it.** Thariq Shihipar (Anthropic, member of technical staff, Claude Code team), ["The new rules of context engineering for Claude 5 generation models"](https://claude.com/blog/the-new-rules-of-context-engineering-for-claude-5-generation-models) (claude.com/blog, 2026-07-24) — the primary source. Surfaced via Duncan Rogoff | Learn Claude Code, ["Anthropic Engineers Just Fixed Claude Code and Nobody's Talking About it!"](https://www.youtube.com/watch?v=UBFHTHUs1wA) (2026-07-28, claude_lab feed) walking through the article and demoing `/doctor`.

**Evidence it's real.** Not a single blogger's read — cross-checked six ways: the primary Anthropic/claude.com article itself; independent trade-press corroboration with matching numbers and dates (KuCoin, CryptoBriefing, Techstrong.ai, AI Weekly, Mike Gingerich, Developers Digest); a critical/contrarian take (CodeBun on Medium, ["Everyone Says Claude Code Cut Its System Prompt by 80%. The Real Story Is More Interesting."](https://medium.com/@codebun/everyone-says-claude-code-cut-its-system-prompt-by-80-the-real-story-is-more-interesting-8e9b56bda96c)) that I deliberately sought out to stress-test the headline number — it confirms the 80% figure is real but points out the comparison is specifically memory-enabled vs. memory-disabled system prompt, not a blanket "we deleted junk" claim, so I'm not overstating it here: the underlying six-shift guidance and the `/doctor` tool are what's actionable, not the raw percentage. I also verified locally rather than trusting the video: `claude --version` → `2.1.220` (current), and `claude doctor --help` confirms the command is real and installed on this machine right now, not vaporware or a future feature.

**Need it serves.** Directly serves the credit-resilience need (`credit-resilience-plan.md`) and this week's memory-cost finding (2026-08-01, fleet-optimizer/STATUS.md) — but from the unaddressed angle: every one of the fleet's ~15+ role workspaces loads its own CLAUDE.md **every single session**, and the global `~/.claude/CLAUDE.md` loads in **every session across the entire fleet**. I checked the actual sizes: `~/.claude/CLAUDE.md` 8.6KB, `~/observer-system/CLAUDE.md` 8.0KB, `~/fleet-optimizer/CLAUDE.md` 13.3KB — none catastrophic individually, but paid on every session start, fleet-wide, indefinitely, and never audited against Anthropic's own current guidance for the model generation actually running (Sonnet 5 / Opus 5 / Fable 5 — confirmed these are what's in use per `~/.claude/settings.json`). Serves priority 2 (the multi-agent unlock: leaner, faster session starts compound across every delegated worker and headless summon) and priority 3/resilience indirectly (the fleet's own cap-gate crisis this week is exactly the kind of burn pressure a smaller fleet-wide fixed cost per session helps against, without touching any judgment call).

**Whole-fleet leverage.** This is a **zero-build, zero-cost lever** — the tool already ships in the installed binary, and this fleet has never run it against its own CLAUDE.md files or checked its guidance (verified: no mention of "claude doctor" system-prompt right-sizing, "context engineering," or CLAUDE.md bloat-trimming anywhere in `~/fleet-optimizer/STATUS.md` or `~/observer-system/STATUS.md` — the one existing `/doctor` mention, 2026-06-09, was an unrelated settings.json permission-rule catch). Every role's CLAUDE.md compounds the same way `credit-resilience-plan.md`'s "detection is free" framing already argues for triage cost — this is the equivalent move for the fixed cost every session pays before any work starts.

**Build sketch.**
1. Run `claude doctor` (or `/doctor` interactively) against the global `~/.claude/CLAUDE.md` and each role workspace's CLAUDE.md — it's read-only first and reports before changing anything, so this is safe to run broadly without a build.
2. Cross-read each flagged file against the six shifts in Thariq's article specifically: is always-loaded guidance that's actually conditional (only relevant to specific tasks) sitting in CLAUDE.md instead of a lazily-loaded skill? Is there a prescriptive rule that's now redundant with Sonnet-5/Opus-5/Fable-5-class judgment?
3. Start with the highest-leverage file: `~/.claude/CLAUDE.md` (loads in every session, fleet-wide) — this project's own `brainrot-radio/CLAUDE.md` (5.8KB) is actually a good positive control since it already follows the progressive-disclosure pattern ("This file holds only the true globals... loaded on demand"), so use it as the reference shape when trimming the others.
4. Don't treat the 80% number as a target — treat `/doctor`'s own findings plus the six shifts as the criteria, and measure before/after token cost on a representative session start for one role before rolling the pattern to all of them.
5. This is exploratory/measurement work, not a judgment call about trading or money — safe to greenlight broadly; flag any role touching `mojo-daemon`/`arena-bot` CLAUDE.md files for a lighter touch given their money-adjacency, per standing fence discipline.
