# Build-Pitch of the Day — 2026-11-11

## Pitch 1 (primary): Adopt goal-bound execution — "delegate an outcome, not a turn"

**Technique.** Claude Code's shipped `/goal` command sets a completion condition and keeps the session working autonomously turn-over-turn until a lightweight judge (Haiku by default, overridable via `ANTHROPIC_DEFAULT_HAIKU_MODEL`) confirms the condition, returning one of three verdicts — not yet met / met / impossible — through a session-scoped Stop-hook-driven loop that composes with Auto mode for unattended operation.

**Who's doing it.** Anthropic — Claude Code documentation, "Keep Claude working toward a goal" (`code.claude.com/docs/en/goal`), with corroborating practitioner coverage (Jakub Kontra on `/goal`/`/loop`/Stop-hook composition and Auto mode; Cameron Shields on the independent per-turn judge). In-fleet precedent: the brainrot-radio QC gate already runs the deterministic cousin — re-running until a greppable `QC VERDICT: PASS/FAIL` line holds.

**Evidence it's real.** Primary-source doc plus practitioner sources converge on the mechanism (Haiku judge, three verdicts, Stop-hook wrapper, Auto-mode composition, stop-on-no-tool-use-with-progress). In-fleet, the deterministic verdict loop was proven end-to-end by the podcast QC fix (known-bad episodes previously shipped on a FAIL path). The planner side of the same autonomy story is now Anthropic-shipped: Fable 5.2 (launched 2026-11-09) with the advisor mechanism (Sonnet executor → Fable advisor ≈84% vs ≈75.5% solo on SWE-bench Pro, ~63% of the cost).

**Need it serves.** Fleet pain: a delegated worker stops when it *feels* done — half-green branches, unverified changes handed back — which is the missing autonomy glue under the multi-agent-without-Kyle vision. Serves priority 2 (AI-business multi-agent collaboration that carries work forward without Kyle's attention) primarily; priority 1 (screenwriting attention) via fewer half-finished agent runs; priority 3 (trading-bot resilience) via the same stop-too-early failure in the triage lane.

**Delta vs Kyle's current setup.** The `/delegate` skill already carries §2b-i (bind the goal through `dispatch-worker.sh`'s `[initial_prompt]`); the brainrot QC gate already runs the deterministic loop. The delta is making outcome-binding the default completion contract fleet-wide rather than a convention applied ad hoc — and never judge-binding money/trading safety conditions.

**Whole-fleet leverage.** One adopt per agent loop: "delegate an outcome, not a turn" — every dispatched worker (task dispatcher, PR-reviewer, beat reporters, sentinel triage) inherits a real completion condition instead of self-reported done.

**Build sketch.**
1. Host is on Claude Code 2.1.321 — past the `/goal` gate (≥2.1.139); before arming goal loops on unattended lanes, verify the 2.1.318 `loginExpiresAt` unattended-lane sign-in canary.
2. `/delegate` §2b-i: make goal-binding the default path when the success criterion is mechanically checkable; keep the deterministic verdict loop as the headless/cron fallback (pattern already proven in the QC gate).
3. `dispatch-worker.sh` + task dispatcher: require a greppable success condition for PR-bearing / verification-bearing dispatches; bind via initial prompt; cap convergence.
4. Guardrails: judge-checkable conditions only (exit code, CI status, file exists, queue empty); never bind money/trading safety conditions to a judge; Auto mode for unattended operation; stop-and-report if the loop stalls.
