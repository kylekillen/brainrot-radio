## PITCH 1 (Primary): Omnigent — Orchestrate the Entire Agent OS Under a Unified, Cost-Controlled Meta-Harness

**Technique:** Omnigent is an open-source "meta-harness" that sits one layer above individual agent CLIs (Claude Code, Codex, Pi, or custom agents) to unify them into a single, stateful session layer. It enables cross-vendor multi-agent workflows (e.g., Claude Code implements, Codex reviews), stateful data-centric policies and cost budgets enforced at the infrastructure layer (below the prompt), and real-time session sharing across terminal, web, and mobile.

**Who's doing it:**
- **Databricks AI Team** (Matei Zaharia, Kasey Uhlenhuth, Corey Zumar) — officially announced and open-sourced Omnigent under Apache 2.0 on June 15, 2026. Blog post: https://www.databricks.com/blog/introducing-omnigent-meta-harness-combine-control-and-share-your-agents
- **Cole Medin** — demonstrated it live in his video "Omnigent: The New Meta-Harness for EVERY Coding Agent - Claude Code, Codex, Pi, More".
- **Prompt Engineering** — broke down the architecture and ran live multi-agent sessions in "Omnigent: The meta-harness that brings all coding agents together!"
